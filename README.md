## コーディングエージェントで進める5段階

A・B・C・F・G・H・Iには、最初のプロンプト例があります。例を参考に、自分の言葉でやりたいことを伝えてください。各段階で返ってきた内容や実行結果を見て、次に何を頼むか自分で考えます。まだ決まっていないことは、エージェントと相談しながら決めてください。

1. **まず、やりたいことを伝える。** 何を調べたいか、何を比べたいかを伝えます。作りたい図表が決まっていれば、それも添えます。
2. **Dockerまたはcondaで環境を作る（B1はColab）。** 自分のPCや使うツールに合わせて、Dockerコンテナかconda環境を選びます。Bのモデル作成（B1）はGoogle ColabのCPUランタイムを使います。必要なツールとバージョン、起動方法を記録し、選んだ環境でツールが動くことを確認します。
3. **解析スクリプトを作る。** 元データの列、入力と出力、絞り込みや集計の条件を確認し、スクリプトを作ります。どこまで決まったかを見て、次の依頼に含める条件を考えます。
4. **小さなデータでテストし、結果を検証する。** 手計算できる数行や模擬データで、先に期待する結果を決めます。実行結果と照合し、違いがあれば原因を調べ、修正してもう一度試します。
5. **ログを取りながら本解析を行う。** テストが通ったら、課題で使うデータを同じ環境とスクリプトで解析します。データの登録番号かURL、使った範囲、設定、実行コマンド、実行時の出力やエラーをログに残します。図表を確認し、スクリプトとログを一緒に保存します。

公開リポジトリやプロンプトには、公開データか、模擬データと明記したものを使います。D・Eは、やりたいことを講師・補助員に伝え、各ページの公開図や記入例から進めます。一部の発展課題は、講師によるデータの準備が必要です。
