# C｜AAV挿入座位を数え、PCRによる偏りを考える

公開ITR-seqの集計値を描き直し、模擬データで数え方を試す案です。

**使える方法**　コーディングエージェント　**まとめ方の例**　挿入座位の集計図と、カウントの偏りを示す模擬例

挿入座位、リード、投入ゲノムのどれを数えるかで、結果の読み方が変わります。[ITR-seqの研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10659022/)では、重複のない挿入座位（unique integration loci、UILs）の集計値が公開されています。

## まず、やりたいことを伝えるときの例

コーディングエージェントにやりたいことを伝えるなら、例えば次のように言えます。

> AAVが挿入された座位の数を論文データから比べたいです。PCRでリードの重複や検出漏れが起きると、数え方によって結果がどう変わるかも見たいです。

その後の依頼を考えるときは、直前の結果や[共通の進め方の例](../README.md#agent-workflow)が参考になります。

## 挿入座位数の集計と模擬データの手順例

1. Table 1から、組換えAAV群と野生型AAV群のマカクの集計値を拾います。Figure 1Aとともに報告された、投入ゲノム100個あたりの挿入座位数の群平均を点で描きます。論文の群名、単位、各群のサンプル数を図に添えます。補足資料にサンプル別の値があればFigure 1Aの一部を再現し、染色体と座位が分かれば1群について染色体別に集計します。
2. 二つの座位で投入分子数が等しい模擬データを作ります。一方の座位で重複リードが増える場合と、もう一方の座位で検出漏れが起きる場合を個別に試します。リード数、回収した分子数、検出した座位数を比べます。
3. 公開データの図と模擬データの結果を別々に保存し、それぞれの分母を記録します。

**テストで確かめられること**　公開データから図に使った値を一つ選び、出典の行と照合します。模擬データでは、重複リードが増えたときと検出漏れが起きたときに、リード数、回収分子数、座位数がそれぞれどうなるかを手で数えます。

**別の題材**　ヌクレアーゼのoff-target候補を探す場合は、[B2のソフトウェア比較](B.md#candidate-search)も参考になります。リン酸化プロテオームを選ぶ場合は、EGFR–MAPK経路のリン酸化部位を3〜5か所選んで時間変化を描きます。欠測値は欠測のまま残します。
